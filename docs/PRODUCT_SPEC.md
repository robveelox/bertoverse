# Product specification — milestone 0.1

## Product promise

A cosy, slightly mischievous social hangout built around original pixel art, decorating, conversation, and community-made rooms. The stoner identity is communicated through colour, humour, botanical motifs, ambient music, and fictional fantasy plants—not real-world drug sales or consumption mechanics.

## Playable milestone

The prototype is complete when:

1. A player enters a display name and joins the lobby.
2. Two browser windows see one another within one second.
3. Clicking or tapping a reachable tile moves the avatar along a valid path.
4. The server rejects blocked, diagonal, out-of-bounds, or impossible moves.
5. Room chat appears above avatars and in a compact chat log.
6. The layout works with mouse, touch, phone, tablet, and desktop widths.
7. The server reconnects gracefully and never accepts client-authored coordinates as truth.

## Non-goals for 0.1

Accounts, registration, inventory, furniture placement, trading, currency, moderation UI, multiple rooms, and production deployment come later. Their database foundations are included so the prototype can grow without a rewrite.

## Originality boundaries

- No Habbo/Nitro/Polaris code, packets, assets, catalogue data, terminology, or room layouts.
- New avatar proportions, palette, interface language, icons, furniture silhouettes, and animation timing.
- Isometric projection and tile-based social-room concepts are treated as generic mechanics; all expression is original.
- Run a trade-mark search before choosing the public name.
